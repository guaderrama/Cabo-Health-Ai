🔍 Verificación de Variables de Entorno

Este HTML NO puede ver import.meta.env porque no es un módulo de Vite.

⚠️ Instrucciones para Verificar

Para verificar las variables de entorno, necesitas hacerlo desde la aplicación principal:

  1. Ve a: http://localhost:3001
  2. Abre DevTools (F12)
  3. Ve a la pestaña Console
  4. Ejecuta estos comandos:
// Ver todas las variables
import.meta.env

// Ver solo el API key
import.meta.env.VITE_GEMINI_API_KEY

// Ver Supabase URL
import.meta.env.VITE_SUPABASE_URL
