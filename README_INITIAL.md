# Cabo Health Nova - Asistente Médico con IA Conversacional

> Asistente de voz para médicos con transcripción en tiempo real, generación de resúmenes SOAP y persistencia de sesiones.

## 🚀 Descripción

Cabo Health Nova es una aplicación web avanzada que permite a los profesionales médicos realizar consultas conversacionales con pacientes utilizando inteligencia artificial. La aplicación incluye:

- **Conversación de Voz a Voz**: Comunicación natural médico-paciente
- **Transcripción en Tiempo Real**: Conversión automática de audio a texto
- **Resúmenes SOAP**: Generación automática de historias clínicas estructuradas
- **Persistencia de Sesiones**: Recuperación automática de consultas interrumpidas
- **Historial de Consultas**: Almacenamiento seguro en base de datos

## 🛠️ Tecnologías

- **Frontend**: React 18.3 + TypeScript 5.6 + Vite 6.0
- **Backend**: Supabase (PostgreSQL, Edge Functions, Storage, Auth)
- **IA**: Gemini 2.5 Flash Native Audio
- **Audio**: WebRTC + Web Audio API
- **UI**: TailwindCSS + Radix UI Components
