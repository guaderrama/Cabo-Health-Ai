🚀 Ejecutar Migración SQL

Sigue estos pasos simples para actualizar tu base de datos

⚠️ Importante: Este proceso toma menos de 2 minutos y es completamente seguro. Solo agrega nuevas columnas, no borra nada.

1 Abre el SQL Editor de Supabase

Haz click en este enlace para abrir el SQL Editor:

https://supabase.com/dashboard/project/cozsoshuctvhvdbmkmwc/sql/new

Se abrirá en una nueva pestaña. Si te pide iniciar sesión, usa tus credenciales de Supabase.

2 Copia este SQL

Haz click en el botón "Copiar" para copiar todo el SQL:

-- Migración: Agregar campos a consultations
-- Fecha: 2025-01-18

-- 1. Columnas del paciente
ALTER TABLE consultations
ADD COLUMN IF NOT EXISTS patient_name TEXT,
ADD COLUMN IF NOT EXISTS patient_dob DATE,
ADD COLUMN IF NOT EXISTS patient_email TEXT;

-- 2. Datos de consulta
ALTER TABLE consultations
ADD COLUMN IF NOT EXISTS transcript JSONB DEFAULT '[]'::jsonb,
ADD COLUMN IF NOT EXISTS summary TEXT,
ADD COLUMN IF NOT EXISTS motivation_score NUMERIC(3,1);

-- 3. Métricas de sesión
ALTER TABLE consultations
ADD COLUMN IF NOT EXISTS session_duration INTEGER DEFAULT 0,
ADD COLUMN IF NOT EXISTS message_count INTEGER DEFAULT 0;

-- 4. Hacer patient_id nullable
ALTER TABLE consultations
ALTER COLUMN patient_id DROP NOT NULL;

-- 5. Crear índices
CREATE INDEX IF NOT EXISTS idx_consultations_user_id ON consultations(user_id);
CREATE INDEX IF NOT EXISTS idx_consultations_session_id ON consultations(session_id);
CREATE INDEX IF NOT EXISTS idx_consultations_created_at ON consultations(created_at DESC);

3 Pega y Ejecuta

En la ventana del SQL Editor de Supabase:

1. Pega el SQL que copiaste (Ctrl+V o Cmd+V)

2. Click en el botón verde "Run" (esquina superior derecha)

3. Espera 2-3 segundos

✅ Deberías ver el mensaje: "Success. No rows returned"
Esto es normal y significa que funcionó perfectamente!

4 Prueba la Aplicación

Ahora vuelve a la aplicación y:

1. Refresca la página (F5)

2. Inicia una nueva sesión médica

3. Al finalizar, completa nombre y fecha de nacimiento

4. Click en "Guardar"

🎉 ¡Ahora debería guardar sin errores!
