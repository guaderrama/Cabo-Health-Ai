🔧 Arreglar Políticas RLS

Las consultas no aparecen en el dashboard del médico porque las políticas de seguridad (RLS) están bloqueándolas.

⚠️ Problema: El dashboard solo muestra 3 de 6 consultas porque RLS filtra por usuario.
✅ Solución: Ejecutar este SQL para permitir que los médicos vean TODAS las consultas.

Pasos a seguir:

  1. Abre el SQL Editor de Supabase
    🚀 Abrir SQL Editor
  2. Copia el SQL de abajo
    -- Eliminar políticas viejas DROP POLICY IF EXISTS "Users can view own consultations" ON consultations; DROP POLICY IF EXISTS "Allow authenticated users to read consultations" ON consultations; DROP POLICY IF EXISTS "Anyone can view consultations" ON consultations; DROP POLICY IF EXISTS "Doctors can view all consultations" ON consultations; DROP POLICY IF EXISTS "Users can insert own consultations" ON consultations; -- Crear nueva política: Médicos ven TODAS las consultas CREATE POLICY "Doctors can view all consultations" ON consultations FOR SELECT USING ( (auth.jwt() -> 'user_metadata' ->> 'role')::text = 'doctor' OR auth.uid() = user_id ); -- Permitir que usuarios inserten sus propias consultas CREATE POLICY "Users can insert own consultations" ON consultations FOR INSERT WITH CHECK ( auth.uid() = user_id );
  3. Pega el SQL en el editor
    Usa Ctrl+V para pegar en el SQL Editor que se abrió
  4. Ejecuta el SQL
    Haz clic en el botón "Run" (o presiona Ctrl+Enter)
  5. Recarga el dashboard del médico
    Presiona Ctrl+Shift+R para recargar la página
🎉 Resultado esperado: Deberás ver las 6 consultas en total:
  • asds (nueva)
  • web

  • arttt
  • arte
  • ivan guaderrama

¿Qué hace este SQL?

El SQL modifica las políticas de seguridad (RLS) para que:

  • ✅ Los médicos (role='doctor') puedan ver TODAS las consultas de todos los pacientes
  • ✅ Los pacientes solo vean sus propias consultas
  • ✅ Todos puedan guardar nuevas consultas
