🔧 Si ves error "Invalid API key"

Posibles causas:

  • Vite no está cargando el .env: Reinicia el servidor de desarrollo completamente
  • Caché del navegador: Presiona Ctrl+Shift+R para forzar recarga
  • Variables mal configuradas: Verifica que tengan el prefijo VITE_
  • Error en Vercel: Configura las variables en Vercel Dashboard
